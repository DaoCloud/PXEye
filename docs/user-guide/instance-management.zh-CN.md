# 实例管理

[English](instance-management.md) · **简体中文** · [页面使用指南](README.zh-CN.md)

## 1. 用途与入口

进入 **资源 → 实例管理**，查看 NICo Instance 的设备、地址、OS 和租户配置，或在退租时回收设备。Instance 是 NICo 的服务器分配资源；页面读取已有实例，装机时的分配由[安装任务](installation-tasks.zh-CN.md)处理。

## 2. 字段填写

| 项目 | 含义 / 填写要求 |
| --- | --- |
| 搜索实例 | 输入名称、ID、SN、主机名或 IP。 |
| 实例名称 / ID | NICo 实例标识；删除前核对目标实例。 |
| 设备 SN / 主机名 | 实例关联设备及主机名，页面同时显示主机名来源。 |
| NICo 实例地址 / OS | NICo 实例配置中的地址及 OS，不等于已完成 OS 登录验证。 |
| 机器状态 / 回收进度 | 当前 Machine 状态与独立回收记录。 |
| 删除确认 | 输入页面显示的完整设备 SN，并确认允许清理本机全部磁盘。 |

## 3. 操作步骤

### 查看

1. 点击**刷新数据**，搜索目标实例。
2. 点击**详情**，查看 Machine、租户、配置版本和最近 Scout 磁盘清单。

### 退租回收

1. 确认设备不再承载需要保留的系统和数据；活动安装任务须先处理完毕。
2. 点击**删除（退租回收）**，核对实例、SN 和全部磁盘范围，输入 SN 并完成确认。
3. 点击**确认删除并回收**，在**回收记录**查看状态；需要时点击**查看记录**、**刷新记录**。
4. 等待**回收完成**并核对机器状态，再继续安装。

## 4. 填写示例

搜索 `SERIAL-1`，确认结果对应待退租实例。删除确认中输入 `SERIAL-1`，确认全部磁盘清理后提交；保留回收记录直到完成。

## 5. 注意事项

- 删除会回收实例及关联资源，可能重启设备并清理全部磁盘；设备规划与安装历史保留。
- 实例从列表消失后，设备可能仍在准备中；不能仅凭记录消失就开始使用设备。
- 请求结果待核对或回收失败时，先刷新并处理 NICo / Scout 错误，避免重复提交。
- 删除不可用时查看原因，解决活动任务、身份关联或已有回收操作等阻塞。
