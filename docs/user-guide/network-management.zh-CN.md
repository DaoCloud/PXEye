# 网络管理

[English](network-management.md) · **简体中文** · [页面使用指南](README.zh-CN.md)

## 1. 用途与入口

进入 **资源 → 网络管理**，查看 NICo 子网并创建装机所需网段。设备发现、地址规划及主机安装会使用这些子网；单台设备的固定地址在**设备管理 → 地址管理**配置。

### 网络要求

- **服务连接**：PXEye 能访问 NICo Core，正常读取和创建子网。
- **地址规划**：明确 IPv4 子网、网关、MTU和保留地址范围；新子网不能与 NICo 已有网段重叠。
- **DHCP 路径**：客户端广播能到达 NICo DHCP 服务；跨子网时配置 DHCP Relay，转发至实际服务 IP 的 UDP `67`，并保证请求与应答双向可达（客户端使用 UDP `68`）。Relay 的 `giaddr` 应属于客户端所在的 NICo 子网；本页不填写 `giaddr`，也不配置交换机 Relay。
- **装机连通**：NICo 能访问设备管理接口，待安装主机能访问实际使用的 PXE/HTTP 引导及安装材料服务；相关 VLAN、路由和访问规则已配置。

## 2. 字段填写

点击**新增子网**，按现场规划填写：

| 字段 | 填写要求 | 示例 |
| --- | --- | --- |
| 子网名称 | 必填；1–128个英文字母、数字、`_`、`.`或`-`，不能使用空格、中文或`static-assignments`。 | `host-install` |
| 网络类型 | 按下表选择；默认HostInband。 | `HostInband · 主机带内` |
| 子网 CIDR | 必填；单个IPv4网络地址加掩码，不能填某台设备的地址。 | `192.0.2.0/24` |
| 网关 | 需要跨网段通信时填写实际网关；在子网内，不能为网络或广播地址。 | `192.0.2.1` |
| MTU | 默认`1500`；整数`576–9216`，与现场链路一致。 | `1500` |
| 起始保留地址数 | 默认`0`；从网络地址开始计数，非负且小于子网总地址数。 | `11`保留本例的`.0–.10`。 |
| DNS 域 | 通常自动关联，无需填写UUID；存在多个域且无法自动确定时，按域名选择。HostInband创建前，站点须已有可用DNS域。 | `example.internal` |
| DHCP 起始 / 结束地址 | 可选，须同时填写或同时留空；包含两端，同属当前IPv4子网，不能包含网关。填写后替代起始保留地址数。 | `192.0.2.100` / `192.0.2.200` |
| 地址策略 | 当前新增只支持**动态分配**。 | `动态分配` |

| 网络类型 | 使用场景 |
| --- | --- |
| HostInband · 主机带内 | 主机直接接入的引导/管理网络；BMC是否共享按站点设计确认。 |
| Admin · 管理 | 受管DPU模型中，主机未分配租户时使用的管理网络。 |
| Underlay | BMC、DPU、交换机BMC/NVOS和供电框PMC等基础管理网络，按实际NICo拓扑选择。 |

## 3. 操作步骤

### 查看

点击**刷新数据**，找到目标子网，点击**查看**核对类型、前缀、网关、MTU和关联接口。已有子网可以单独配置DHCP地址池；名称、CIDR、网关及MTU不能修改。MTU在**新增子网**中填写，默认1500；已创建子网的详情只展示MTU，没有编辑入口。设备规划表不单独设置MTU，附加静态网口在安装时继承所属子网MTU。

### 创建

DNS域用于组织设备主机名及地址记录，与DNS服务器IP不同。NICo在创建域对象时生成其UUID；新增子网引用已有域，不会为每个子网创建新域。系统优先使用唯一可用的站点正向域；有多个时可沿用现有HostInband子网共同使用的域，否则按域名选择。租户域、已删除域及反向域不作为候选。

1. 点击**新增子网**，填写并核对上述字段。
2. 点击**创建到 NICo**，系统自动关联DNS域、检查格式与前缀重叠，并创建、读回配置；无需另存草稿。
3. 在子网列表找到新记录，点击**查看**确认与规划一致。
4. 为服务器配置管理网时，在**设备管理 → 系统配置**选择该HostInband范围；CSV规划的`management_subnet`须与已有子网CIDR完全一致。

### 配置 DHCP 地址池

1. 点击目标子网的**查看 → 配置 DHCP 地址池**，填写起始和结束IP，例如`192.0.2.100`至`192.0.2.200`。
2. 点击**应用**；成功后列表展示NICo读回的范围。子网仍为`192.0.2.0/24`，固定地址保持独立。
3. 起止地址同时留空并应用，恢复按子网及起始保留地址数分配。

范围外已有动态分配时，系统列出冲突并保留原配置，不回收租约。池内已占用和固定分配的地址不会重复分配。仅支持单IPv4前缀的站点子网；不改变IPv6策略或租户网络。Core不支持时页面提示升级，不会提交不支持的范围配置。升级要求见[部署指南](../deployment.zh-CN.md#dhcp-地址池支持)。

### 删除

1. 确认子网已不用，并移除设备规划引用、释放关联接口和地址。
2. 点击**删除**，核对名称和范围，勾选确认后提交。
3. 在**子网删除进度**查看状态，刷新至目标子网消失。

系统地址段只显示说明，不展示删除按钮。其他子网的删除按钮不可用时查看旁边原因；租户网络及站点配置管理的子网不能在此删除。

## 4. 填写示例

下面使用文档专用地址；到现场须替换为实际规划。

| 项目 | 填写值 |
| --- | --- |
| 名称 / 类型 | `host-install` / `HostInband · 主机带内` |
| CIDR / 网关 | `192.0.2.0/24` / `192.0.2.1` |
| MTU / 起始保留地址数 | `1500` / `11`，保留`.0–.10`。 |
| DNS 域 | 自动关联站点已有域；无法确定时按域名选择。 |
| 地址策略 | `动态分配` |

填写后点击**创建到 NICo**。本例`.11–.254`还需扣除实际占用地址，才能用于动态分配；网关、网络和广播地址由分配器另行排除，不重复加算保留数量。

## 5. 注意事项

- **确认生效**：子网出现在列表或显示`READY`，不代表DHCP已可用；还需客户端实际请求并取得预期网段地址。
- **固定地址**：创建子网不会将设备改为规划IP；BMC地址需单独执行更新，主机管理地址由安装任务应用。
- **地址策略**：标注“站点配置”或“创建默认”时是配置来源，尚未确认当前实际策略；“待确认”表示无法确定。
- **异常处理**：创建或删除超时，先刷新核对NICo结果，避免重复提交；提示已有操作执行中时等待后再试。
