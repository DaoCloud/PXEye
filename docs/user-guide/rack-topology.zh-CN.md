# 机柜拓扑

[English](rack-topology.md) · **简体中文** · [页面使用指南](README.zh-CN.md)

## 1. 用途与入口

进入 **总览 → 机柜拓扑**，按机柜查看服务器、交换机、供电框和 DPU 端点。用于定位设备、查看管理地址，并按现场习惯排列设备卡片。

## 2. 字段填写

本页读取已有设备信息，只需在编辑布局时拖动卡片。

| 显示项 | 含义 / 维护位置 |
| --- | --- |
| 机柜 | 按设备的 NICo Rack 归属分组；没有归属的设备显示在未关联分组。设备机柜归属在设备配置中维护。 |
| 设备 SN、BMC 地址、管理地址 | 来自设备清单；地址优先展示实际观测值，没有时展示规划值。通过[设备管理](device-management.zh-CN.md)维护。 |
| DPU 数量 | 按已识别的 DPU 接口展示；顶部“DPU 节点”统计具有 DPU 接口的设备数。 |
| 电源圆点 | 最近读取的电源状态；绿色为开启，灰色为关闭，空心为未知；悬停查看状态及时间。 |
| 布局 | 网络与交换、计算托盘、其他设备、供电分区内的卡片顺序。 |

## 3. 操作步骤

1. 点击**刷新拓扑**，读取最新清单；点击设备卡片查看详情。
2. 点击**编辑布局**，在同一机柜、同一分区内拖动设备调整顺序。
3. 点击**保存布局**保留排列，或点击**取消**放弃本次未保存调整。
4. 需要恢复自动排序时，进入编辑布局，点击**恢复自动排列**；该操作立即清除所有机柜已保存的人工排列。

## 4. 填写示例

`RACK-01` 的计算托盘分区中已有 `SERIAL-1` 和 `SERIAL-2`。将 `SERIAL-2` 拖到前面并保存；再次打开页面时按保存顺序展示。

## 5. 注意事项

- 拖动只改变展示顺序，不修改机柜归属、硬件地址或物理接线。
- 当前展示逻辑分组，不提供真实 U 位、物理高度或交换机链路图。
- CSV 设备规划里的机柜字段用于对比；一键匹配不会改变 NICo Rack 归属。
