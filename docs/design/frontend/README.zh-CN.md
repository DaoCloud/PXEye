# 整机柜运维前端设计稿

[English](README.md) · **简体中文** · [设计文档](../README.zh-CN.md)

面向 GB200 / GB300 整机柜的 PXEye 前端页面设计。它是前端实现的参考：页面可点击，样式和写法与现有产品一致，每个页面带自己的功能说明。数据全部是编写的示例，不连接任何站点，也不是已实现的功能。

## 打开

在检出的仓库里用浏览器直接打开 `docs/design/frontend/index.html`，不需要构建和服务器。页面直接引用 `src/pxeye/web/` 下的产品样式文件，所以要在仓库里打开，不能单独拷走这个目录。

## 页面说明在哪

每个页面的说明（定位、入口、功能点、字段、规则、弹窗）写在该页面脚本的 `spec` 里，和页面的渲染代码在同一个文件。它有三种看法，来源只有这一份：

| 看法 | 在哪 | 用途 |
| --- | --- | --- |
| 页面右侧的“页面说明”面板 | 顶栏“页面说明”，或面板收起后右侧的竖条 | 边点边看当前页面的说明。面板可以收起、展开和加宽，始终把页面推开，不覆盖页面内容 |
| 页面上的编号标注 | 顶栏“功能点标注” | 编号与说明里的功能点一一对应；鼠标移到说明上会高亮页面元素 |
| 全部页面说明 | 顶栏“全部页面说明”，或 [page-spec.zh-CN.md](page-spec.zh-CN.md) | 评审和打印 |

`page-spec.zh-CN.md` 是生成的文件，不要直接修改。改了页面或它的 `spec` 之后重新生成：

```bash
node docs/design/frontend/tools/build-spec.mjs
```

功能点的类型：**沿用**表示与现有产品页面一致，**调整**表示在现有基础上修改，**新增**表示现有产品没有。界面是简体中文，页面说明随界面只有简体中文。

## 左侧菜单

菜单按“对象直达”组织：设备按类型各有自己的入口，不需要先进机柜；机柜是关联与汇总视图。带子菜单的菜单项可以折叠：点文字进入该页面并展开，点箭头只切换折叠。

| 分组 | 菜单项 |
| --- | --- |
| 运维 | 机柜管理；NVLink 域管理；设备管理（子菜单：计算托盘、交换机、供电框、DPU）；健康告警；运维任务；操作审计 |
| 交付 | 机柜交付；安装任务；实例管理 |
| 接入 | 网络规划；设备清单；设备发现 |
| 配置 | 站点设置；固件基线；安装方案 |

“接入”三项按使用顺序排列：先规划网段，再导入设备清单，通电后查看设备发现。网络规划检查不通过时不能导入设备清单。

菜单名用四个字的正式名称，页面标题与菜单名一致，子菜单是设备类型名。菜单上的数字都表示需要关注的数量，不是总数。一级菜单的字号和间距与产品一致，颜色加深、字重略增；子菜单小一号、颜色较浅。

## 用词

界面文字统一用中文，不把英文缩写和中文拼成一个词。固定用词：安装方案、交换机、机柜上线（对应 NICo 的 bringup）、就绪、序列号、开机与关机、阻止分配。三类设备统称“设备”，“计算托盘”只作为其中一类的名称。

保留原文的只有两类：产品与组件名（NICo、NVLink、RMS、Flow、BMC、PMC、NVOS、DPU、Fabric Manager），以及 NICo 状态机回报的状态值（如 Ready、Maintenance），后者按“显示状态原文”的规则不翻译。

## 结构

| 文件 | 内容 |
| --- | --- |
| `index.html` | 外壳。样式引用 `src/pxeye/web/` 下的 `styles.css`、`live.css`、`nico.css`，设计稿不带副本 |
| `design.css` | 设计稿新增的组件样式和标注层；进入实现时把新组件部分迁入产品样式 |
| `app.js` | 运行时：`registerPage` / `registerAction`、`heading` / `table` / `button` / `badge` / `modal`，签名和类名与产品的 `shared/live.js` 一致 |
| `data.js` | 示例数据和任务模拟；实现时替换为 NICo Core 与 Flow 的接口 |
| `pages/*.js` | 页面脚本，每个页面带 `spec` |
| `pages/operations.js` | 机柜、NVLink 域、设备的写操作和门控 |
| `tools/build-spec.mjs` | 从页面脚本生成 `page-spec.zh-CN.md` |

## 讲解

右侧面板的“讲解与模拟”里有十步讲解主线和几个模拟开关：通电并发现新机柜、泄漏告警、RMS 不可用、Flow 不可用、重置示例数据。顶栏可以切换三种角色：只读不能执行任何操作；操作可以执行设备、机柜和交付操作；管理另外可以修改站点、网络和安装方案。
