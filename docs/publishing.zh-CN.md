# 公开发布准备

[English](publishing.md) · **简体中文** · [文档中心](README.zh-CN.md)

## 仓库边界

公开仓库为 [SSmallMonster/PXEye](https://github.com/SSmallMonster/PXEye)。原开发工作区内，`services/os-install-console/` 是独立 PXEye 仓库根目录。父级工作区包含上游源码、环境记录和私有资料，不是一个 PXEye 仓库。

公开范围包括源码、中英文文档、品牌素材、部署骨架和编写的界面示例数据。排除上游 checkout、现场部署覆盖、Secret、SQLite、OS 材料、原始控制台日志、现场设备清单和第三方二进制。历史环境笔记保留在项目目录之外，公开变更记录按能力里程碑组织。

## 发布准备

1. 保留已选定的 [Apache-2.0 许可证](../LICENSE)及第三方声明。
2. 核对名称和软件包可用性，保留独立项目声明。
3. 配置私密漏洞报告渠道，同时更新两种语言的安全文档。
4. 检查源文件及导入的 Git 历史，清除凭据、私有清单和环境数据；ignore 规则不能清理已有历史。
5. 核对依赖、字体、图标和其他分发素材的许可证及 NOTICE。
6. 在干净 checkout 中准备兼容且已核验的二进制和站点配置，再构建镜像。
7. 只验证已授权的部署和硬件路径，并准确标注证据范围。
8. 发布标签前核对中英文文档、本地链接和截图来源。

## 首版范围

首个公开版本定位为技术预览，提供 NICo 资源视图、设备发现与规划、网络和 OS 材料管理、安装方案、串行装机流程，以及日志、恢复和验收记录。

不承诺多用户 RBAC、分布式执行、通用硬件兼容或生产 SLA。[参考截图](reference-cluster.zh-CN.md)用于展示界面，不是已部署客户集群或 GB200 安装成功的证据。
